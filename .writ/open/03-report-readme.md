# first user の報告：writ/README.md

対象：`writ/README.md`（行番号はこのファイルのもの）
読み手と目的：writ に初めて出会う Claude Code の利用者。読み終えて、writ から何を得るかを知り、使うかを決め、使い始められる。
使った観点：`references/essentials/doc.md`、`references/essentials/readme.md`。そのあと、同じ使い方について `references/essentials/essentials.md` の問いに答えた。

読み方：初めての Claude Code 利用者として、上から一度通して読んだ。入れるコマンドは指示どおり走らせず、README の手順をたどるだけにした。ほかのファイル（リンク先の観点ファイル、設計書、LICENSE）は開いていない。

読み手として定めたこと：読み終えて「writ を入れるかを決め、入れるなら入れて最初の `/writ:up` を呼ぶ」。
