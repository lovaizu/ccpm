Where should a first user, an agent that knows nothing of how the work was made, use the work before
you see it? Each use costs one agent run you wait through; each place left out is left to whoever
made it, writing to its viewpoints, and to you at the sign-off.

- Task results and the deliverable only (recommended): these are the places where running the work
  shows what its maker cannot see. The plan, the design, questions and proposals are written to their
  viewpoints by the conductor and `writ`, and read by you. Fastest; a gap in the design shows only
  when a task is built on it.
- Those, and the design once before `writ` writes it: a first user tries to build from the agreed
  design points, so gaps show before the documents are written (as #39 proposes). One run more per
  design; catches design gaps earlier.
- As today: also the plan, every question and every proposal, and each fix again. What you saw today.
