## NG — the claim does not hold as written

### NG-1 — "Turns never nest" is not structural

- **Claim**: design.md:41 "Turns never nest. Only the Conductor spawns." design.md:233 "Rules 1–2 are
  structural — fresh contexts come from the platform, and a work order that spawns nothing cannot nest."
- **Reality**: the platform permits nesting. Docs, subagents: "Subagents can also spawn subagents of
  their own," to a default depth of 3 (`CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`, "`1` stops your subagents
  from spawning any of their own").
- **What is true**: nesting is prevented by omitting the spawn tool from each Turn definition, which is
  structural once done (per OK-3). The wall holds; the stated reason for it does not.

### NG-2 — "Turns cannot talk to people" is false by default

- **Claim**: design.md:199 "Turns cannot talk to people."
- **Reality**: a subagent inherits every tool available to subagents when `tools` is omitted, and the
  user-question tool is among them. Silence is achieved by leaving it out of the definition, not by the
  platform.
- **What is true**: the same fix as NG-1 — the Turn definitions must name their tools explicitly.

### NG-3 — the Conductor's wall cannot be made physical by the plugin

- **Claim**: design.md:386 "Where the implementation allows, read-class tools may be cut off from the
  Conductor — part of this wall can be made physical."
- **Reality**, mechanism by mechanism:
  - **Deny rules** do remove a tool outright — docs, permissions: "A bare tool name like `Bash` removes
    the tool from Claude's context entirely, so Claude never sees it." But a plugin cannot ship them:
    docs, plugins reference — a plugin's settings support "Only the `agent` and `subagentStatusLine`
    keys." The user must configure them.
  - **Path-scoped deny** (`Read(src/**)`) leaves the tool available and blocks matching calls — but
    permission rules are session-wide: docs, subagents, on plugin agents — "these rules apply to the
    entire session, not only the plugin subagent." A rule that stops the Conductor reading the real work
    would stop the Turns reading it too, and the Turns are the only ones that may.
  - **A PreToolUse hook** can be shipped by a plugin and can block a call, but that is a guard evaluated
    per call, not removal from the tool list.
  - **`disallowedTools`** on an agent definition binds only that subagent, never the main session.
- **Compounding fact**: the Conductor's entire working state is files — the latest CCS, the Plan,
  approved phase documents (design.md:388). It cannot be denied Read at all.
- **What is true**: a real physical route exists, but it changes how aiya is launched. Docs, subagents:
  "When an agent runs as the main thread with `claude --agent`, it can spawn subagents using the Agent
  tool," and its `tools` field is an allowlist — the shipped example is a `coordinator` with
  `tools: Agent(worker, researcher), Read, Bash`. Run that way, Grep, Glob, Bash, Edit and Write can be
  physically absent from the Conductor while each Turn keeps its own set. Read must remain.

### NG-4 — "the existing async chat surface" names no surface

- **Claim**: design.md:209 "the Conductor stops, posts a bounded summary on the existing async chat
  surface, and waits."
- **Reality**: `README.md` shows two distinct surfaces — the bounded summary in the console
  (README.md:65-70) and the artifact itself reviewed on the PR (README.md:67 "review it on the PR").
  The design names neither.
- **Consequence**: under the session rule that the experience decides the surface, the design must say
  what the README shows.

### NG-5 — a skill cannot self-run between gates

- **Claim**: design.md:209 "Between gates the Conductor self-runs — re-planning included."
- **Reality**: a skill is prompt text loaded into the session, holding no execution state. A turn ends
  when the model stops calling tools; nothing resumes it but the human's next message. Self-running holds
  within one turn's tool-calling loop, and stops at the turn boundary.
- **What is true**: the design already carries the correct remedy elsewhere — the resume point is the
  latest CCS, the approved phase documents and the current Plan (design.md:215), which is file-held state,
  not skill-held state. Only the sentence at :209 overstates it.

### NG-6 — wave width has an undocumented ceiling

- **Claim**: design.md:163-167 treats wave width as unbounded ("no matter how wide the wave").
- **Reality**: docs, subagents — "By default, when 20 subagents are running in a session, spawning
  another with the Agent tool fails with `Concurrent subagent limit reached`."
- **Consequence**: a wave wider than the cap needs a dispatch rule the design does not have.

### NG-7 — a sourcing claim carries no source

- **Claim**: design.md:413 "The nine-component cognitive structure of the CCS is adopted from research
  literature."
- **Reality**: no citation appears anywhere in the document set.
- **Consequence**: the session rule "Curate, never invent — anything shipped as a standard carries its
  source" is not met by this sentence.

## Proposals — awaiting the user's ruling

No document is edited until these are ruled on. One judgment call, six wording fixes.

### The judgment call: NG-3, the Conductor's wall

The design says read-class tools can be physically cut off from the Conductor. No mechanism a plugin
can ship does this, and the Conductor cannot lose Read at all — its own working state (Plan, CCS,
approved documents) is files.

- **Proposal A (recommended)** — rewrite design.md:386 to say the wall is an instruction, kept by the
  Turn-definition side (each Turn's tools are pinned; the Conductor's are not), observable when broken
  (design.md:388 already defines the tell). The design already concedes at :43 and :417 that rules not
  made structural are "default and observable" and that prompt compliance is the bet — this puts :386
  inside that frame instead of contradicting it. UX unchanged.
- **Alternative B** — run the Conductor as the main thread of a dedicated launch (`claude --agent`),
  whose `tools` allowlist genuinely strips Grep/Glob/Bash/Edit/Write. The only true physical wall, but
  it replaces the approved install-and-`/aiya:on` experience, and Read still remains.
- **Alternative C** — ship a PreToolUse hook that blocks the Conductor's reads by path. Stays a plugin,
  but the tool stays visible-yet-blocked, and it adds machinery before the bet it would reinforce has
  been measured. Viable later as hardening; wrong as a first move.
