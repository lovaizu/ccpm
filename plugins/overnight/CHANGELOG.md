## [Unreleased]

### Added

- overnight runs a piece of work in Claude Code while you're away, and resumes it by itself after the usage limit or an error stops it, so you find it done by morning, or recorded as failed with its log.
- overnight keeps the works you add in a queue and runs them one after another, starting the next when one ends, done or failed, so that one command each before you leave carries the whole night. `overnight` with no work given goes on with the works that wait, after a restart of the computer.
