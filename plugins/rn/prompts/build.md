# The build stage of /rn:up

Step 10 of `/rn:up`, from the design approved to the deliverable sign-off, taken as
`orchestrator.md` says.

10. Build the finished work, task by task, and stop at the deliverable sign-off, so the user
    decides from the proposal alone.
    - In: the design approved, the stage build.
    - Write the plan again, step 3 on work `plan`, giving nothing more, with the tasks that build
      the finished work.
    - Carry out each task in order, step 4.
    - Once the steering holds no task: `rn.py state --stage deliverable --message <m>`, which sets
      Next this step on `deliverable`. Have the finished work used: step 3 on work `deliverable`,
      giving nothing more.
    - Then step 5 on the deliverable sign-off.
    - Out: the deliverable sign-off waiting.
