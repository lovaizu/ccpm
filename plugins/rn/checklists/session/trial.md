# Trial

A trial result, a file in the session's folder `.rn/<yyyymmdd>-<slug>/`, where rn keeps one piece of
work, tells of a small try of a way before it is built on. It is used by the user deciding a point
it bears on, and by the maker of each later work it is handed to by name, to tell whether that way
works before they rest their decision or their work on it.

A trial result serves them by what was run and what came out, as it came out: the way tried, the
check that says whether it works, set before the run, and the result against that check, with what
was run told so that another can run it again and get the same. What the try did not cover is said,
so the reader knows how far the result holds.

## Benefit

### B-1: Whether the way works

Scope: its part

From the opening, can the reader tell which way was tried, for which point or work, what check
says whether it works, and whether it passed?

Signs: the reader reads a check that gives the same answer whoever reads the output, rather than
one such as "runs well"; the check was set before the run, not fitted to what came out; the verdict
is on what was tried, such as one command of a tool rather than the whole tool.

Why: the user decides and the maker builds on the verdict; one without a check, or with a check
fitted to the output, is a reading of the output that another would read otherwise, and one wider
than the try is built on where it was never tried.

### B-2: Run again by another

Scope: its part

Can another run the trial again from what it says alone and get what it shows: what was set up,
with the version of each tool and the inputs, the commands or steps as they were run, and what came
out, as it came out?

Tried by: the steps the verdict rests on run again from what the trial says alone, each as it is
told, and what came out set beside what it shows.

Signs: the reader runs each step as it was run, not from a summary; they read the output as it came
out, whole where the verdict rests on it; each version, setting and input is named; each file the
trial ran on is where they can reach it.

Why: a trial no one can run again is believed or doubted on the word of whoever ran it, and a
result that changes with a version shows the change only when someone runs it again.

### B-3: How far the result holds

Scope: whole

Can the reader tell what the trial did not cover, such as cases not run, a larger size or another
platform, and each thing that failed or was worked around on the way?

Signs: the reader reads in the result each failure seen in the run, and each fault worked around,
such as a setting changed by hand; the result is said of the cases the try ran.

Why: a way tried on less than it is built for fails where it was not tried, and a failure or a
work-around left out is met again by the maker who builds on the way.
