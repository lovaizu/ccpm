# The design stage of /rn:up

Step 9 of `/rn:up`, from the plan approved to the design sign-off, taken as its SKILL.md says.

9. Make the documents the purpose needs and stop at the design sign-off, so the user approves how
   the work will meet the goal before it is built.
   - In: the plan approved, the stage design.
   - Hear which documents the purpose needs, such as a UX, a README and an architecture, in the
     order their checklists draw them, UX, README, architecture: step 2 on work `plan`, each a
     decision naming the document's path and its kind, `ux`, `readme`, `architecture` or the user's
     own. Where the user decides the purpose needs none, run `rn.py state --stage build --message
     <m>`, which sets Next step 10, and go on to step 10, as no design sign-off is needed.
   - Write the plan again, step 3 on work `plan`, giving nothing more, with a task for each
     document.
   - Carry out each task in order, step 4; once the steering holds no task, step 5 on the design
     sign-off.
   - Out: the design sign-off waiting.
