# Report

What a first user returns after using a work: for each viewpoint, what it understood from the work,
or what happened when it did as the work says. With it, the conductor sets each answer beside the aim
and gives a Good or a More, each checked at its place in the real thing, without asking back. The
first user of a report takes it up as the conductor would, with the work, the aim, and the viewpoints
the report answers.

- For which viewpoint could you give neither a Good nor a More from the report?

    The conductor can then decide every viewpoint from the report, since each answer is what was
    understood or what happened. An answer that is a verdict, a feeling, or a fix, or no answer at
    all, leaves the viewpoint undecided or decided by the first user's guess instead of the aim.

- Which answer could have been given without using the work?

    An answer from use is what the user would meet, so a Good given on it holds when the user uses
    the work. An answer from looking the work over passes a work no one can use.

- Doing at each answer's place what the answer says was done, what happened that differs from the
  answer?

    The conductor can then trust each answer, and a Good given on it holds when the user reads that
    part, since no one looks again at what is called good.
