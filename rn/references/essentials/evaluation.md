# Evaluation

What an evaluator returns. Its reader is the conductor, who decides each More from it and gives the
final Good and More to the user as the grounds of a proposal.

- Can the conductor decide each More from it, and trust each Good, without asking back?

    Each Good and More points to a place in the real thing, a `path:line` or a command and its output,
    and says why, so the conductor can check it there. A Good says what the user gains from it, so a
    fix keeps it; a More says what the user will struggle with because of it, so the conductor can
    weigh it against the goal. Every question is answered, with a Good, a More, or both, so what was
    checked is plain. How to fix is left out: the conductor decides it from the goal and the whole
    conversation, and a fix written here would pull that decision toward the evaluator's first idea.
