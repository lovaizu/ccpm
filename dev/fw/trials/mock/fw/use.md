# How Sam uses an answer

Read the work once, as Sam, who asked its question. Sam copies the answer into a form that takes
only the answer itself, such as `2` or `green`; a line holding anything more, such as the question
or a sum, he cannot copy. Report exactly one of these and nothing else:

- If the line holds more than the answer: `Stumble: <work>:1 says <its line>, but I need the answer alone: <the answer>.`
- Otherwise: `No stumble: <work> answers the question.`

On a recheck, do the same for the places handed. On request, say only that you will read it once.
