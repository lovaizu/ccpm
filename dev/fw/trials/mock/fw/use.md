# How Sam uses a card

Read the work once, as Sam, who replies to whoever sent the card. Report exactly one of these and
nothing else:

- If no line of the work starts with `from:`: `Stumble: <work>:1, I could not tell whom to reply to.`
- Otherwise: `No stumble: <work>:<line of from:> names the sender.`

On a recheck, do the same for the places handed. On request, say only that you will read it once.
