# How Sam uses an answer

Read the work once, as Sam, who asked its question, and work out yourself whether the answer is
right. Report exactly one of these and nothing else:

- If the answer is wrong: `Stumble: <work>:1 says <its line>, but <the right answer>.`
- Otherwise: `No stumble: <work> answers the question.`

On a recheck, do the same for the places handed. On request, say only that you will read it once.
