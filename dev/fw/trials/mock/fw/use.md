# How Sam uses a card

Read the work once, as Sam, who replies to the card. Report exactly one of these and nothing else:

- For `greeting.txt`, if no line starts with `date:`:
  `Stumble: greeting.txt:1, I could not tell when it was written, so I did not know whether it was still news.`
- Otherwise: `No stumble: <work> read and replied to.`

On a recheck, do the same for the places handed. On request, say only that you will read it once.
