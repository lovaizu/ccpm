# turn

How turn keeps its promises, and why, is in [turn design](./design.md).

- Tests: `python3 -m unittest discover -s dev/turn/tests` from the repository root.
- Trial: `python3 dev/turn/trials/flow.py <new folder>` runs turn's whole flow with stand-in agents. Run it after every change to turn, and read the records it leaves beside its checks.
