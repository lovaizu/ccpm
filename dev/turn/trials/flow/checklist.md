# Short README

A short README lets someone who finds the tool run it on their own file, from one screen.

## Benefit

### B-1: Run it

Can the reader install the tool and run it on their own file?

### B-2: License

Can the reader tell under which license they may use the tool?

### B-3: The result

Can the reader see, before running the tool, a sample file of several rows as it is and as the tool
leaves it?

### B-4: Every link opens

Can the reader open every file the README links to, in the repository as they find it?

## Format

### F-1: One screen

Is the README ten lines or fewer, code blocks included?
