# taskctl 1.4.0 (2026-09-29)

## Changed

- The config file has moved from `~/.taskctlrc` to `~/.config/taskctl/config.json`, to match where other tools keep theirs. 1.4.0 does not read `~/.taskctlrc`. After upgrading, move it like this:

  ```console
  $ mkdir -p ~/.config/taskctl
  $ mv ~/.taskctlrc ~/.config/taskctl/config.json
  ```

  If you run it without moving the file, it stops with a message telling you to move it.

## Added

- You can now export only the tasks due on or after a given date, as in `taskctl export --since 2026-10-01`. Tasks with no due date are left out.

## How to upgrade

```console
$ npm install -g @taskboard/taskctl@1.4.0
```
