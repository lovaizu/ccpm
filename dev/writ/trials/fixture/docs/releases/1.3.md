# taskctl 1.3.0 (2026-08-04)

## Added

- `taskctl export --format csv` now writes CSV. Besides the existing JSON, you can open the output directly in a spreadsheet app. With no format given, it still writes JSON as before.

## Fixed

- Opening a file written with `--out` in Excel showed garbled text for titles with non-ASCII characters. This is fixed: the CSV now starts with a BOM.

## How to upgrade

```console
$ npm install -g @taskboard/taskctl@1.3.0
```
