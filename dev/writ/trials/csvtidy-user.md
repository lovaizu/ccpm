# What the user of the csvtidy trial knows

You wrote csvtidy, and you have asked writ for its README. You know:

- It is for developers whose scripts break on CSV exports with stray spaces and empty rows.
- Over tidying the file in a spreadsheet: it tidies a whole folder in one command, and keeps each
  original beside it as `<name>.orig.csv`.
- It is published on GitHub at github.com/example/csvtidy, and not yet on PyPI; it installs with
  `pip install git+https://github.com/example/csvtidy`.
- It is under the MIT license.

Anything else you were not told; say you do not know, and let writ decide.
