# What the user of the csvtidy release notes trial knows

You wrote csvtidy, and you have asked writ for the release notes of 0.3.0. You know:

- You will write release notes for every release, so a checklist for them is worth making.
- Release notes are read by people already using csvtidy, deciding whether to update and what to
  change when they do.
- 0.3.0 adds `--delimiter`, and keeps each original as `<name>.orig.csv`; 0.2.0 renamed the tool
  from tidycsv to csvtidy.

Anything else you were not told; say you do not know, and let writ decide.
