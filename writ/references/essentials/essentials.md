# Essentials

The readers are the producing role, which reads the essentials as the shape to aim for, and the checking role, which reads them as questions to answer. When they finish, they can judge any part of any work by whether the receiver of the work needs it, including parts no one foresaw.

- Can the question be answered only by someone who understands the receiver's purpose?

    If someone could satisfy it by form alone, it is a rule, such as "show an example" or "put it in a table". The producing role then meets it where it does not help, and the checking role passes work that misses the purpose because the form is there. A question answered from the state of the finished work, not from whether steps were followed, keeps the judgment on the purpose. What a script can decide belongs in a script, not in a question.

- Does each question find both what is missing and what is extra?

    A question that asks only whether something is there finds only gaps, so every fix adds text and the work grows each round. A question that lets the reader judge what taking a part away would lose finds both.

- Does each question cover every part it concerns, without listing cases?

    A list of situations stands in for the purpose behind it. It grows with every new case and still misses the case no one listed, while the purpose covers them all.

- Does the explanation under each question give only why the receiver needs it?

    An explanation says what the receiver struggles with when the question fails, and may show an example. Steps and flow rules placed there are followed as rules where they do not fit, and pile up with each fix; they belong in the design or the prompt.

- Are the questions few enough to remember, each tracing to a benefit the receiver would choose the work for?

    Each question catches together the errors that arise from one cause. With non-essential questions, the producing role's aim drifts, there is more to read, and fixing never ends. When the checking role's answers are shallow, the questions are too many or too vague; refine the questions rather than add roles.
