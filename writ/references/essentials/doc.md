# すべての文書

読み手が、上から読み進めるだけで全体をつかみ、読み終えたらすべきことができるか。

- 読み手が1人に絞られているか。

    誰が読むか、読み終えて何を決め何をするか、通して読むか必要なところだけ引くかを、それぞれ1行で言える。文体、順序、図、締め方は、この3つから決める。読み手が2人いるなら、文書を読み手ごとに分ける。

- 読み手に要ることがそろい、どの文も核になっているか。

    網羅せず、核に絞る。核が多すぎるのは、まだ磨き足りないしるし。網羅した詳細が要るときは、別の文書に表でまとめ、本文からリンクする。読み返す人、過去のレビュー役、承認する人など、ほかの人のための文は、この読み手にとっての核ではない。読み手に要るのに入れる場所がないことは、そのための場所を作る。

- どの文も、文書そのものの説明でなく、中身を書いているか。

    最初の1文から核を言う。文書の位置づけ、読み方、使い方、中身の紹介は、題名と中身に語らせる。

- どのことも一度だけ書いているか。

    題名、図、ほかの文から分かることは、そちらに任せる。

- 今決まっている姿だけを書いているか。

    決めるまでの経緯や変更の履歴は、今の姿ではない。

- 中身そのものの欠陥が、欠陥として見えているか。

    決まりの穴や主張どうしの食い違いのように、読み手がつまずく原因が書き方でなく中身にあるときは、文章でつじつまを合わせず、その欠陥をそのまま書く。

- 見出しだけを上から読んで、筋が通るか。

    通して読む節の見出しは、その節の核となる主張か、読み手がそこで抱く問いにする。引いて読む節の見出しは、読み手が探す言葉にする。見出しは、決まった型からでなく、読み手の問いの順に組み立てる。

- 図を見るだけで、その節の核が分かるか。

    登場人物とそのやりとり、順序、分岐、状態の移り変わりは図にする。図は飾りでなく、その節の核を描く。矢印には、何が渡るかを書く。文書やファイルも1つずつ登場人物として描き、誰が書き、誰が読み、どこへ渡るかを描く。全体に流れや構造のある文書は、冒頭に全体の図を置き、そのあとは部分ごとの図に分ける。1枚の図は、一目で追える数の箱にとどめ、縦向きにし、ラベルはその時点で読み手に分かる短い言葉にする。各節は図を先に置く。

- 上から読み進めるだけで、前後を行き来せずに分かるか。

    結論やベネフィットを先に書き、抽象的な型より先に具体的な流れの例を見せる。言葉は、初めて出るところか、それより前で意味が分かる。理由、方針、いつも成り立つ条件、代償、選ばなかったやり方、仮定は、それぞれ関わる決めたことのすぐそばに書き、理由は1文にする。

- 並んだ項目が、説明を読まなくても見渡せるか。

    項目は、それだけで意味が通る1文にする。説明は、項目のあとに空行を入れ、字下げして下に書く。

- 1つのものを、1つのふつうの言葉で呼んでいるか。

    同じ言葉は、いつも同じ意味で使う。専門用語や造語より、ふつうの言葉を選ぶ。役割は、何をするかが分かる名前で呼び、人も個人の名前でなく役割で呼ぶ。物は、使う人に見えている名前で呼ぶ。

- 書いてあることの確かさが、読み取れるか。

    確かめた事実は言い切り、確かめていないことは仮定と書き、決めたことは決めたことと書く。下書きで提案や仮説だったものは、提案や仮説のまま書く。言い切れないところには、根拠か「未確認」を書く。確かめた範囲も書く。いくつかを比べるときは、一方に有利な事実だけを集めず、測った値と判断を分けて並べる。うまくいかない点、代償、限界も書く。

- 読み手に合った文体で、人が書いたように読めるか。

    文体と調子は読み手に合わせて決め、最後までぶらさない。埋め草、言い直し、一般論への逃げ、中身のないつなぎ言葉、要らない箇条書き、ぼかした言い方のような、AI が書いたと分かる癖が残っていない。

- 太字、括弧書き、表は、本当に要るところにだけあるか。

    太字は、読み落とすと判断を誤るところにだけ使う。括弧書きは、ないと誤解されるところにだけ使い、それ以外は本文に入れるか削る。表は、いくつかのものを同じ項目で並べて比べるところと、網羅した詳細をまとめる別の文書にだけ使う。
