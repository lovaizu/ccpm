# ルール・観点・指示の文書

読み手は、その文書に沿って動く人か AI。読んだあと、書いた人が思い描いていなかった場面でも、目的に届く動き方を自分で選べる。

- 手順でなく、届くべきところが渡されているか。

    渡すのは、目的と、届いたかを確かめる観点。手順は字面どおりに守られ、場面が想定と違うと的を外し、書いた人の想定までしか届かない。観点は、磨くほど良くなり、読むモデルが良くなるほどよく効く。手順は、ずれると壊れる受け渡しの形のように、読み手が選ぶ余地のないところだけに書く。

- 目的に、なぜそれが要るかが添えられているか。

    なぜを知っている読み手は、字面の外の場面でも目的に合うほうを選べる。決めてきた経緯は、なぜではない。

- 読み手の役目と、何を自分で決め、何を決めずに返すかが分かるか。

- どの観点も、実物で確かめられる状態で書かれているか。

    成果物ができたことや手順を踏んだことでなく、目的に届いた実物の状態で書く。そうすれば、手段が変わっても観点は成り立つ。

- 作る側と確かめる側が、同じ観点を読むか。

    作る側は観点を狙いとして読み、確かめる側は同じ観点を問いとして読む。確かめる側には、作った側の理由を渡さない。理由を知ると、作った側の見方に寄る。

- 禁止の一覧でなく、根をとらえる問いで書かれているか。

    1つの問いが、同じ根から出る形の違うまちがいをまとめて捉える。一覧は、載っていない形を防げない。

- 別の文書を読ませるところに、パスと読む理由だけがあるか。

    中身の要約を添えると、読み手は本体を読まずに済ませる。

- 各段で使う決まりが、その段にあるか。

    離れた一覧を指すと、読み手は読み飛ばすか、覚えている範囲で済ませる。

- するべきことが、肯定の形で書かれているか。

    無いものの説明、決めてきた経緯、そのときの作業だけの決まりは、するべきことではない。
